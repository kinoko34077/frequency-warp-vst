音声処理方式
ⓘ 説明

チェック中は実際の変換後の主曲線が全体として右下がりならA、それ以外はB。オフなら上の手動選択を使います。Aは目立つ音の成分を再合成し、Bは周波数帯を移す方式です。

ⓘ A方式の説明

精細度はピーク抽出数・閾値・残差補完を連動調節します。抽出帯域幅は近接ピークの分離基準です。音質は実験段階で、高設定はCPU負荷が増加します。

反転と帯域
ⓘ 反転方式の説明

幾何補間は f′=f^(1−a)×I(f)^a。中間で周波数が一点へ重なる場合があります。L/H折返しは入力側に折れ点を生みます。

倍音表示
ⓘ 説明

グラフ下の小窓は最大3倍音、詳細表は選んだ倍音数まで表示します。

計算量・応答性
ⓘ 説明

FFT窓：大きいほど周波数を細かく調べますが、遅延が増えます。重ね合わせ：8×は分析回数が増え、処理が重くなります。変更すると処理状態を作り直します。

数値表示

数値欄・倍音表の見た目を切り替えます。どちらでも直接入力した小数第3位まで音に反映されます。整数設定は整数のままです。

操作
ⓘ 説明

音声ファイルと再生位置はそのまま。研究用試作品のため一部の変更で短い音切れが生じます。
